📘 Module 6: Prompt Engineering Frameworks

📖 Lesson 1: RTF Framework

Full Form

  • R – Role
  • T – Task
  • F – Format

Definition

The RTF Framework is one of the simplest prompt engineering frameworks. It helps create clear prompts by defining:
Role → Who the AI should act as.
Task → What the AI should do.
Format → How the output should be presented.

Why is it Important?

RTF makes prompts:
Clear
Organized
Easy to understand
Easy to reuse

Framework Components

  • Role
  • Task
  • Format

Characteristics

  • Beginner-friendly
  • Simple
  • Reusable
  • Professional

Uses

Blog Writing
Coding
Resume Generation
Teaching
Email Writing

Workflow

Role
↓
Task
↓
Format
↓
AI Response

Real-Time Example

Role:
Senior Python Developer
Task:
Explain Python Lists
Format:
Markdown with examples

Real-Life Analogy

Imagine hiring an employee.
You tell them:
Who they are.
What work to do.
How to submit the work.
That is exactly how RTF works.

📌 Interview Tip

RTF is one of the easiest frameworks for writing structured prompts.
💡 Prompt Engineer Tip

Always define the Role first.

📖 Lesson 2: RISEN Framework

Full Form

  • R – Role
  • I – Instructions
  • S – Steps
  • E – End Goal
  • N – Narrow Constraints

Definition

RISEN is a structured prompting framework that provides the AI with a clear role, detailed instructions, step-by-step guidance, the desired outcome, and specific constraints.

Why is it Important?

It produces:
More accurate responses
Better reasoning
Clear objectives
Consistent outputs

Characteristics

  • Structured
  • Goal-oriented
  • Detailed
  • High accuracy

Uses

Business Reports
Coding
Research
AI Assistants

Workflow

Role
↓
Instructions
↓
Steps
↓
End Goal
↓
Constraints
↓
Response

Example

Role:
Senior Data Scientist
Instructions:
Explain Linear Regression.
Steps:
Start with the definition.
Explain the formula.
Give a real-world example.
Goal:
Teach beginners.
Constraints:
Simple English.
📌 Interview Tip

RISEN is commonly used for educational and business prompts because it provides detailed guidance.

📖 Lesson 19: ReAct Framework

Full Form

  • ReAct = Reason + Act

Definition

ReAct combines reasoning with actions. The AI first reasons about the problem, then decides whether it needs to use external tools or perform actions before producing the final answer.

Workflow

Question
↓
Reason
↓
Choose Tool
↓
Observe Result
↓
Reason Again
↓
Final Answer

Uses

AI Agents
Web Search
Tool Calling
Autonomous Systems

📖 Lesson 20: Chain of Density (CoD)

Definition

Chain of Density (CoD) is a summarization technique where the AI repeatedly rewrites a summary, making it denser by including more important information while keeping the length nearly the same.

Why is it Important?

CoD creates summaries that are:
More informative
More concise
Rich in key details

Workflow

Original Text
↓
Summary V1
↓
Add Important Details
↓
Summary V2
↓
Repeat
↓
Dense Final Summary

Uses

Research Papers
News Summaries
Reports
Executive Briefs
