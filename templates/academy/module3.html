Module 3: Basic Prompting Techniques

📖 Lesson 1: Zero-shot Prompting

Definition

Zero-shot Prompting is a prompting technique where the AI is asked to perform a task without providing any examples. The model relies entirely on its pre-trained knowledge to understand the request and generate a response.

Why is it Important?

Zero-shot prompting is useful when:

  • The task is simple.
  • No example data is available.
  • You need quick responses.
  • The AI already understands the task.

Characteristics

  • No examples provided.
  • Fast and simple.
  • Uses AI's existing knowledge.
  • Best for common tasks.
  • Easy to write.

Uses

Question Answering, Summarization, Translation, Definitions, Brainstorming

Workflow

User Prompt
↓
No Examples
↓
LLM Uses Pretrained Knowledge
↓
Response

Real-Time Example

Prompt:
Explain Artificial Intelligence in simple English.

Real-Life Analogy

Imagine asking a teacher: "What is Gravity?"

The teacher already knows the answer, so no example is needed.

📌 Interview Tip

Q: What is Zero-shot Prompting?
Answer: Zero-shot prompting is asking an AI to perform a task without giving any examples.
💡 Prompt Engineer Tip

Use Zero-shot prompting for: Definitions, General questions, Simple coding, Basic explanations.

📖 Lesson 2: One-shot Prompting

Definition

One-shot Prompting is a prompting technique where one example is provided before asking the AI to perform a similar task.

Why is it Important?

One example helps the AI understand:

  • Expected format
  • Writing style
  • Output pattern

Characteristics

  • One example
  • Better consistency
  • Easy to create
  • More accurate than Zero-shot

Uses

Text Classification, Email Writing, Translation, Formatting

Workflow

One Example
↓
User Task
↓
AI Learns Pattern
↓
Response

Real-Time Example

Input: Apple
Output: Fruit

Now classify:

Input: Dog
Output: Animal

Real-Life Analogy

A teacher solves one math problem before asking students to solve the next one.

📌 Interview Tip

One-shot Prompting uses exactly one example before the actual task.
💡 Prompt Engineer Tip

Use One-shot prompting whenever output formatting is important.

📖 Lesson 3: Few-shot Prompting

Definition

Few-shot Prompting provides multiple examples (usually 2–10) before asking the AI to perform a task.

Why is it Important?

Multiple examples help AI understand complex patterns more accurately.

Characteristics

  • 2–10 examples
  • High accuracy
  • Better consistency
  • Learns output format

Uses

Classification, Data Extraction, Sentiment Analysis, Structured Outputs

Workflow

Example 1
↓
Example 2
↓
Example 3
↓
User Input
↓
Response

Real-Time Example

Input Output
Apple Fruit
Rose Flower
Tiger Animal
Mango ? (AI outputs: Fruit)

Real-Life Analogy

A teacher solves several problems before giving homework.

📌 Interview Tip

Few-shot prompting generally improves accuracy compared to Zero-shot.
💡 Prompt Engineer Tip

Use Few-shot for structured tasks and AI classification.

📖 Lesson 4: Multi-shot Prompting

Definition

Multi-shot Prompting provides a large number of examples to teach the AI a complex pattern before asking it to solve a task.

Why is it Important?

Useful when: Tasks are complicated, Consistency is critical, AI must follow strict patterns.

Characteristics

  • Many examples
  • Highly consistent
  • Better learning
  • Suitable for enterprise AI

Uses

Medical AI, Legal AI, Financial Reports, Enterprise Chatbots

Workflow

Many Examples
↓
Pattern Learning
↓
User Input
↓
AI Response

Real-Time Example

Provide 20 customer support examples before asking AI to answer a new customer question.

Real-Life Analogy

A cricket coach trains a player with hundreds of practice balls before a match.

📌 Interview Tip

Multi-shot prompting is best when output consistency is more important than prompt length.

📖 Lesson 5: Persona Prompting

Definition

Persona Prompting assigns a specific role, profession, or identity to the AI before giving it a task.

Why is it Important?

The AI changes its response style based on the assigned role.

Characteristics

  • Role-based
  • Professional responses
  • Domain-specific
  • More natural

Uses

Teacher, Lawyer, Doctor, Software Engineer, Marketing Expert

Workflow

Assign Role
↓
Give Task
↓
AI Responds as that Role

Real-Time Example

Act as a Senior Python Developer.
Teach Python Functions with real-world examples.

Real-Life Analogy

An actor performs differently depending on the role assigned.

📌 Interview Tip

Persona Prompting improves response quality by giving the AI a clear identity.
💡 Prompt Engineer Tip

Always assign an expert role before asking technical questions.

📖 Lesson 6: Goal Prompting

Definition

Goal Prompting clearly defines the final objective that the AI should achieve before generating a response.

Characteristics

  • Goal-oriented
  • Focused
  • Reduces irrelevant output
  • Better planning

Uses

Business Plans, Project Planning, Resume Writing, Marketing

Example

Goal:
Create a one-page ATS-friendly resume for a Data Scientist.

Workflow

Goal
↓
AI Planning
↓
Response

📖 Lesson 7: Step Prompting

Definition

Step Prompting instructs the AI to solve a task one step at a time instead of producing the final answer immediately.

Why is it Important?

Breaking problems into steps improves clarity and reduces mistakes.

Characteristics

  • Sequential
  • Logical
  • Easier to understand
  • Better accuracy

Uses

Mathematics, Coding, Problem Solving, Tutorials

Workflow

Problem
↓
Step 1
↓
Step 2
↓
Step 3
↓
Final Answer

Example

Explain how to build a website step by step.
📌 Interview Tip

Step Prompting is different from Chain-of-Thought. It asks for structured steps but doesn't necessarily require exposing internal reasoning.

📖 Lesson 8: Output Templates

Definition

Output Templates define the exact structure or format in which the AI should present its response.

Characteristics

  • Structured
  • Reusable
  • Consistent
  • Easy to automate

Uses

HTML, JSON, Markdown, Tables, CSV

Example

Return the answer in this format:

Name:
Skills:
Projects:
Experience:

Workflow

Template
↓
AI Generates Output
↓
Formatted Response

📖 Lesson 9: Style Control

Definition

Style Control guides the AI to write in a specific tone, writing style, or communication format based on user requirements.

Characteristics

  • Controls tone
  • Controls language level
  • Controls writing style
  • Improves consistency

Uses

Professional Emails, Blogs, Social Media, Technical Documentation, Academic Writing

Example

Write in a professional tone.
Use simple English.
Maximum 150 words.

Workflow

Style Instructions
↓
AI Adjusts Tone
↓
Final Response

Real-Life Example

Without Style Control With Style Control
AI writes a formal business email. AI writes a friendly email suitable for students.
📌 Interview Tip

Style Control changes how the AI responds, while Goal Prompting changes what the AI should accomplish.
