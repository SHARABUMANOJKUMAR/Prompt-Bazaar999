📘 Module 10: Retrieval-Augmented Generation (RAG)

🎯 Module Objective

Learn how Large Language Models (LLMs) retrieve external knowledge using Vector Databases and Semantic Search to generate accurate, up-to-date, and context-aware responses while reducing hallucinations.

📖 Lesson 1: What is RAG?

Definition

Retrieval-Augmented Generation (RAG) is an AI architecture that combines a Large Language Model (LLM) with an external knowledge source. Before generating a response, the AI retrieves relevant information from documents, databases, or vector databases and uses that information to produce more accurate, up-to-date, and reliable answers.
Unlike a standard LLM that answers only from its training data, RAG first searches for relevant information and then generates a response based on that retrieved context.

Why is RAG Important?

  • RAG helps AI:
  • Reduce hallucinations.
  • Access the latest information.
  • Answer questions using private company data.
  • Improve factual accuracy.
  • Generate context-aware responses.

Characteristics

Uses external knowledge.
Retrieves relevant documents before answering.
Works with Vector Databases.
Supports private data.
Improves LLM accuracy.

Uses

  • AI Chatbots
  • Legal Assistants
  • Healthcare AI
  • Enterprise Search
  • Customer Support
  • Research Assistants

Workflow

User Question
↓
Convert Question to Embedding
↓
Vector Database Search
↓
Retrieve Relevant Chunks
↓
Context Injection
↓
Large Language Model
↓
Final Answer

Real-Time Example

User asks:
What are the consumer rights under the Consumer Protection Act?
Without RAG:
The AI answers from its training data, which may be outdated or incomplete.
With RAG:
The AI searches the latest Consumer Protection Act documents, retrieves the relevant sections, and generates an answer based on those documents.

Real-Life Analogy

Imagine taking an open-book exam.
Without RAG:
You answer only from memory.
With RAG:
You first open the textbook, find the correct chapter, read it, and then answer the question.

📌 Interview Tip

Q: What is RAG?
  • Answer:
  • Retrieval-Augmented Generation (RAG) is an AI technique that retrieves relevant external information before generating a response, improving accuracy and reducing hallucinations.
💡 Prompt Engineer Tip

RAG is ideal whenever your AI needs to answer questions using private documents or frequently changing information.

📖 Lesson 2: Why Do We Need RAG?

Definition

RAG addresses the limitations of traditional LLMs by allowing them to access external knowledge sources at the time of answering.

Problems Without RAG

  • Hallucinations
  • Outdated information
  • Cannot access private company documents
  • Limited knowledge after training

Benefits of RAG

  • Current information
  • Enterprise knowledge access
  • Better accuracy
  • Trustworthy answers
  • Lower retraining cost

Workflow

LLM Alone
↓
Limited Knowledge
↓
Possible Hallucination
----------------------------
LLM + RAG
↓
Retrieve Documents
↓
Accurate Answer

Real Example

Company Policy Chatbot:
Without RAG → Cannot answer questions about new HR policies.
With RAG → Searches the latest HR policy documents before answering.

📖 Lesson 3: Chunking

Definition

Chunking is the process of dividing large documents into smaller, meaningful pieces called chunks before storing them in a vector database.

Why is it Important?

Improves search accuracy.
Makes retrieval faster.
Reduces irrelevant information.
Fits within LLM context windows.

Characteristics

Smaller document pieces.
Semantic grouping.
Easy retrieval.
Better embeddings.

Types of Chunking

  • Fixed-size
  • Sentence-based
  • Paragraph-based
  • Semantic Chunking
  • Recursive Chunking

Workflow

Large PDF
↓
Chunking
↓
Small Chunks
↓
Embeddings

Example

A 500-page Constitution book becomes thousands of smaller chunks before storage.

📖 Lesson 4: Embeddings

Definition

Embeddings convert text into numerical vectors that capture semantic meaning, allowing AI to compare ideas based on meaning rather than exact words.

Why is it Important?

  • Embeddings enable:
  • Semantic Search
  • Similarity Matching
  • RAG Retrieval
  • Recommendation Systems

Workflow

Text
↓
Embedding Model
↓
Vector
↓
Vector Database

Example

Lawyer → [0.21,0.44,0.61]
Advocate → [0.20,0.45,0.60]
Similar meanings produce similar vectors.

📖 Lesson 5: Vector Databases

Definition

A Vector Database stores embeddings (numerical vectors) instead of plain text, enabling fast similarity search.

Why is it Important?

Stores embeddings.
Enables semantic search.
Supports millions of vectors.
Fast retrieval.

Examples

  • Pinecone
  • Qdrant
  • Chroma
  • FAISS
  • Milvus
  • Weaviate

Workflow

Documents
↓
Embeddings
↓
Vector Database
↓
Search

📖 Lesson 6: Semantic Search

Definition

Semantic Search retrieves information based on the meaning of a query rather than exact keyword matching.

Example

User searches:
"Car"
Semantic Search also finds:
Automobile
Vehicle
SUV
Sedan

Characteristics

  • Meaning-based
  • Intelligent
  • Context-aware
  • Better than keyword search

📖 Lesson 8: Re-ranking

Definition

Re-ranking is the process of reordering retrieved documents based on their relevance before sending them to the LLM.

Why is it Important?

Improves relevance.
Removes noisy results.
Better final answers.

Workflow

Retrieve Top 20 Chunks
↓
Re-ranker
↓
Best 5 Chunks
↓
LLM

📖 Lesson 9: Context Injection

Definition

Context Injection is the process of inserting retrieved information into the prompt before sending it to the LLM.

Workflow

Retrieved Chunks
↓
Prompt Template
↓
LLM
↓
Answer

Example

Context:
Consumer Rights Act...
Question:
What are consumer rights?

📖 Lesson 10: Hybrid Search

Definition

Hybrid Search combines Keyword Search and Semantic Search to improve retrieval accuracy.

Why is it Important?

  • It captures both:
  • Exact keyword matches.
  • Meaning-based matches.

Workflow

User Query
↓
Keyword Search
+
Semantic Search
↓
Merge Results
↓
Best Documents
↓
LLM

📖 Lesson 11: Qdrant

Definition

Qdrant is an open-source vector database optimized for storing and searching embeddings efficiently.

Best For

  • Production RAG
  • AI Chatbots
  • Enterprise Search

📖 Lesson 12: Chroma

Definition

Chroma is a lightweight, open-source vector database designed for local AI development and rapid prototyping.

Best For

  • Local development
  • Small to medium RAG projects
  • Beginners

📖 Lesson 13: Pinecone

Definition

Pinecone is a fully managed cloud vector database that provides scalable, high-performance similarity search for production AI applications.

Best For

  • Enterprise applications
  • Cloud deployment
  • Large-scale AI systems

📖 Lesson 14: FAISS

Definition

FAISS (Facebook AI Similarity Search) is an open-source library developed by Meta for fast similarity search and clustering of dense vectors.
Unlike Pinecone, Qdrant, or Chroma, FAISS is a library, not a standalone database.

Best For

  • Local vector search
  • Research
  • Offline AI applications
