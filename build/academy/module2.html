Module 2: Prompt Engineering Fundamentals

📖 Lesson 1: What is Prompt Engineering?

Definition

Prompt Engineering is the process of designing, writing, testing, and improving prompts (instructions) to help Artificial Intelligence (AI) generate accurate, useful, and high-quality responses.

A prompt engineer communicates with AI by giving clear instructions, context, examples, and constraints.

Why is Prompt Engineering Important?

Prompt Engineering helps:

  • Improve AI response quality.
  • Reduce incorrect or irrelevant answers.
  • Save time by getting better results in one prompt.
  • Increase consistency.
  • Build AI applications like chatbots and assistants.

Characteristics

  • Clear
  • Specific
  • Context-aware
  • Goal-oriented
  • Easy to understand
  • Repeatable

Uses

  • ChatGPT, Claude, Gemini
  • AI Coding Assistants
  • AI Content Writing
  • AI Customer Support

Workflow

User Goal
↓
Write Prompt
↓
AI Processes Prompt
↓
AI Generates Response
↓
User Reviews Result

Real-Time Example

Prompt:
Explain Machine Learning in simple English using one real-life example.

Good Prompt → Good AI Response

Real-Life Analogy

Imagine ordering food.

Bad Prompt Good Prompt
Give me food. Give me one medium Veg Pizza with extra cheese.

The better your instructions, the better your result.

📌 Interview Tip

Q: What is Prompt Engineering?
Answer: Prompt Engineering is the process of designing effective prompts that help AI generate accurate, relevant, and high-quality responses.

📖 Lesson 2: Prompt Anatomy

Definition

Prompt Anatomy refers to the different parts that make up a well-designed AI prompt. A complete prompt usually contains several components that guide the AI.

Main Components

  • Role: Who the AI should act as
  • Task: What the AI needs to do
  • Context: Background information
  • Constraints: Rules to follow
  • Output Format: How to present the answer
  • Examples: Samples of expected output

Structure

Role
↓
Task
↓
Context
↓
Constraints
↓
Output Format
↓
Response

Example

[Role] You are a Python Teacher.
[Task] Explain Lists.
[Context] Use simple English.
[Examples] Give 3 examples.
[Output Format] Answer in bullet points.

Characteristics

  • Organized & Structured
  • Easy to modify
  • Easy to understand

Uses

AI Chatbots, Coding, Report Writing, Content Creation.

📖 Lesson 3: Prompt Lifecycle

Definition

Prompt Lifecycle is the complete process of creating, testing, improving, and maintaining prompts.

Stages

  1. Define Goal
  2. Write Prompt
  3. Test Prompt
  4. Evaluate Output
  5. Improve Prompt
  6. Final Prompt

Workflow

Goal
↓
Draft Prompt
↓
AI Response
↓
Evaluate
↓
Improve Prompt
↓
Final Prompt

Characteristics

  • Iterative
  • Continuous Improvement
  • Quality Focused

Real Example

Version 1 Version 2
Write Python. Write a Python program to sort numbers using Bubble Sort with comments.

Note: Version 2 produces much better results.

📖 Lesson 4: Prompt Design Principles

Definition

Prompt Design Principles are best practices for writing clear, structured, and effective prompts.

Principles

  • Be Clear
  • Be Specific
  • Give Context
  • Define Goal
  • Specify Output Format
  • Add Constraints

Characteristics

  • Simple, Precise, Consistent, Easy to follow

Uses

Business AI, Education, Programming, Content Writing.

Example

Bad Prompt Good Prompt
Explain AI. Explain Artificial Intelligence to a Class 10 student using simple English and one real-life example.

📖 Lesson 5: Instructions vs Context

Definition

Instructions tell AI what to do. Context gives AI background information.

Difference

Instructions Context
Task Background
Direct command Supporting information
Short Detailed

Example

Instruction: Summarize the article.

Context: The article is about Climate Change.

Workflow

Instruction
↓
Context
↓
AI Understanding
↓
Response

Uses

Better AI responses, Accurate outputs, Personalized AI.

📖 Lesson 6: Delimiters

Definition

Delimiters are special symbols used to separate different parts of a prompt.

Common Delimiters

"""
'''
---
###
<<< >>>
[]
{}

Example

Summarize this text:

"""
Artificial Intelligence is...
"""

Characteristics

  • Organized
  • Cleaner prompts
  • Less confusion

Uses

Long Documents, RAG, APIs, Coding.

📖 Lesson 7: Variables

Definition

Variables are placeholders that can change dynamically inside prompts.

Example

Name = Ravi

Prompt: Write a birthday message for

Output: Happy Birthday Ravi!

Characteristics

  • Reusable
  • Flexible
  • Dynamic

Uses

Email Automation, Chatbots, CRM, Personalized AI.

Workflow

Variable
↓
Prompt Template
↓
AI
↓
Personalized Response

📖 Lesson 8: Constraints

Definition

Constraints are rules or limitations that tell AI what it should or should not do.

Examples

  • Maximum 100 words
  • Use bullet points
  • Don't use technical terms
  • Only English
  • Include examples

Characteristics

  • Controlled, Consistent, Accurate

Uses

Exams, Reports, Legal Writing, Coding.

Example

Explain AI in 50 words.
Use simple English.
Do not use technical jargon.

📖 Lesson 9: Output Formatting

Definition

Output Formatting specifies how AI should present its response.

Formats

  • Bullet Points
  • Table
  • JSON
  • HTML
  • Markdown
  • CSV, XML

Example

Return the answer as a Markdown Table.

Characteristics

  • Readable, Structured, Professional

Uses

APIs, Reports, Dashboards, Documentation.

📖 Lesson 10: Examples (Few-Shot Prompting)

Definition

Examples are sample inputs and outputs provided inside a prompt to help AI understand the expected response format.

Example

Input Output
Apple Fruit
Dog Animal
Rose Flower

Characteristics

  • Consistent
  • Better Accuracy
  • Easy Learning

Uses

Classification, Translation, Coding, Data Labeling.

📖 Lesson 11: Negative Prompting

Definition

Negative Prompting tells AI what not to include in its response.

Example

Explain AI.
Do not use technical terms.
Do not write more than 100 words.

Characteristics

  • Removes unwanted output, Better control, Cleaner responses

Uses

Image Generation, Chatbots, Content Writing, Coding.

Real Example

Without Negative Prompt With Negative Prompt
Generate a logo. Generate a logo.
Do not use black color.
Do not add shadows.
Do not use gradients.

📖 Lesson 12: Prompt Evaluation

Definition

Prompt Evaluation is the process of checking whether a prompt produces accurate, useful, consistent, and high-quality responses.

Evaluation Criteria

  • Accuracy, Relevance, Completeness, Consistency, Clarity, Safety

Workflow

Prompt
↓
AI Response
↓
Evaluate
↓
Improve Prompt
↓
Better Response

Characteristics

  • Objective, Repeatable, Quality-focused

Uses

AI Products, Enterprise Chatbots, Testing, Prompt Optimization.

Real-Time Example

Prompt 1 Prompt 2
Explain Python. Explain Python for beginners using simple English, one real-life example, and fewer than 150 words.

Note: The second prompt is more effective because it is clearer, more specific, and easier for the AI to follow.
